# Keyboard Shortcuts

Shortcuts in the HiveMind OS desktop app. Where this page lists `Ctrl` or `Cmd`, either key works. Flight Deck is the exception: it listens for the Control key on every platform, including macOS.

## Chat

| Shortcut | Action |
|---|---|
| `Enter` | Send the message |
| `Shift+Enter` | Insert a newline |
| `Escape` | Close the @-mention list |

Type a command at the start of the message to open its list:

| Typed text | Action |
|---|---|
| `/prompt` or `/p` | Pick a prompt template on the current persona |
| `/workflow` or `/wf` | Pick a chat workflow to launch |
| `@` | Insert a file from the session workspace |

## Navigation

| Shortcut | Action |
|---|---|
| `Ctrl+B` or `Cmd+B` | Show or hide the sidebar |
| `Ctrl+Shift+F` | Open or close Flight Deck. Use the Control key, including on macOS. |

## Workflow designer

These apply while the workflow designer is open and focus is not in a text field, except Save, which works from a field.

| Shortcut | Action |
|---|---|
| `Ctrl+S` or `Cmd+S` | Save |
| `Ctrl+Z` or `Cmd+Z` | Undo |
| `Ctrl+Shift+Z`, `Cmd+Shift+Z`, `Ctrl+Y`, or `Cmd+Y` | Redo |
| `Ctrl+A` or `Cmd+A` | Select every node |
| `Ctrl+Shift+L` or `Cmd+Shift+L` | Auto-layout the graph |

## Spatial canvas

| Shortcut | Action |
|---|---|
| `Ctrl+F` or `Cmd+F` | Search cards |
| `Delete` or `Backspace` | Remove the selected edge, when focus is not in a text field |
| `Escape` | Close search, or clear the selected edge |
